# Week 1 - Day 1 Projects

This day’s projects focus on understanding the REPL (Read-Eval-Print Loop) concept along with practicing interactive input and output in Python programs.

# Projects demonstrating REPL and input/output concepts:

budget_tracker.py – Allows users to input expenses and savings to calculate and track their budget interactively.  
financial_calculator.py – Enables users to input loan and interest details to compute financial summaries.  
currency_converter.py – Takes user input to convert amounts between different currencies.  
todo_list.py – Lets users interactively manage a list of tasks (add, view, remove items).

# Input and output examples using Python:

calculator.py – A basic calculator program that takes user input to perform arithmetic operations and displays the results.  
grade_calculator.py – Accepts grades as input and calculates the overall score or grade output.  
movie_recommender.py – Takes user preferences as input and outputs movie recommendations.
