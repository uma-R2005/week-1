# Week 1 - Day 5 Projects

This day’s projects focus on understanding core Python data structures such as lists and tuples, alongside practicing basic assignments to build foundational programming skills.

## Projects demonstrating lists, tuples, and assignments:

- shopping_cart.py  
  This script provides a practical example of how lists work in Python by implementing a simple shopping cart system. Users can add items, remove items, and view the current list of products. It highlights the mutability of lists and common list operations such as appending, removing, and iterating over items.

- color_analysis.py  
  This script explores the concept of tuples in Python using color analysis as an example. Tuples are immutable sequences, and this project demonstrates how to define tuples, access elements, and use tuples in practical applications where data should not be modified after creation.

- assignment.py  
  This assignment requires writing Python code to compute the **mean**, **median**, and **mode** of a list of numeric scores **without using any external libraries**. It is designed to deepen understanding of basic statistics and algorithm implementation.  
  The program should:  
  - Calculate the average (mean) of the scores.  
  - Determine the median value after sorting the scores.  
  - Identify the mode(s), i.e., the most frequently occurring score(s).  
  The implementation must be done from scratch, without using built-in statistics libraries, and handle cases such as multiple modes or empty inputs gracefully.
