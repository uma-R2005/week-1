# Week 1 - DAY-3 Python Assignments

This repository contains Python programs demonstrating control flow: if/else examples. Each script showcases practical implementations of conditional statements to solve real-world problems and programming exercises.

# Files and Descriptions

- `atm_machine.py`  
  Simulates ATM operations like balance inquiry, withdrawals, and deposits, using if/else statements to handle different user inputs and transaction conditions.

- `fridge_inventory.py`  
  Manages a fridge inventory by checking stock levels and expiration dates, using conditional logic to alert when items are low or expired.

- `library_return_fines.py`  
  Calculates fines for library books based on return status—on time, late, or lost—and applies discounts or warnings depending on the user type.

- `smart_lighting.py`  
  Automates lighting controls by analyzing environmental data such as time and motion detection, employing if/else decisions to switch lights on or off.

- `assignment.py`  
  Implements the FizzBuzz challenge by categorizing numbers from 1 to 100 into separate lists for those divisible by 3, 5, or both, demonstrating conditional flow control.
